# 简截 SnapLite — 项目文档集

简截是一个常驻托盘、跨 Windows / macOS 的轻量截图工具。只做四件事：

1. **区域截图**：框选屏幕区域，复制到剪切板或保存为 PNG。
2. **长截图**：框选一个可滚动区域，自动（或手动）滚动并拼接成一张长图。
3. **简单标注**：矩形框、椭圆、箭头、画笔，换色、换粗细、撤销/重做。
4. **剪切板历史**：记录最近复制的图片和文字，点一下即可重新放回剪切板。

UI 框架使用 [Viva](https://github.com/vivaui/viva)（Go 编写、GPU 原生、无 WebView 的桌面框架，固定 `v0.2.1`）。

## 执行约定（给实现者）

- 严格按 [06-开发计划.md](06-开发计划.md) 的里程碑顺序做，每个里程碑结束时跑一遍该里程碑的“完成标准”。
- 文档与 Viva 实际 API 冲突时，**以 Viva v0.2.1 源码为准**，并在 [03-技术架构.md](03-技术架构.md) 末尾的「偏差记录」里写一行说明改了什么、为什么。
- Viva 的 Agent 指南在其仓库 `docs/skills/building-with-viva/SKILL.md`，写 UI 代码前先读；示例在 `examples/guides/`。本地 Go 模块缓存里可以直接读源码：`$(go env GOMODCACHE)/github.com/vivaui/viva@v0.2.1/`。
- 不要在开发中打开真实窗口去“看效果”（会打扰用户、触发系统权限弹窗）；UI 用 `app.Driver` 测试验证，真实窗口验收留给 [07-测试与验收.md](07-测试与验收.md) 的手工清单。
