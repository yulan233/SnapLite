# 06 开发计划

按里程碑顺序执行。每个里程碑结束时运行该里程碑的**完成标准**命令，全部通过才进入下一个。任何里程碑都不需要打开真实窗口。

通用完成标准（每个里程碑都要满足）：

```bash
gofmt -l .                                   # 输出为空
go vet ./...
go test ./... -count=1
GOOS=windows GOARCH=amd64 go vet ./...
GOOS=windows GOARCH=arm64 go build ./...
go build -o build/snaplite ./cmd/snaplite
```

## M0 项目骨架

- `go mod init snaplite`，`go get github.com/vivaui/viva@v0.2.1`。
- 读 Viva 的 `docs/skills/building-with-viva/SKILL.md` 与 `examples/guides/{hello,drawing,input,overlay,windows}`（在模块缓存里），确认：`RunApplication`、`OpenWindow`、`AddStatusItem`、`DrawBitmap`、`DrawPath`、保存对话框、光标 API 的真实签名。与 03 文档 §2 不符之处写入偏差记录。
- 建 03 文档 §3 的目录，各包放 `doc.go`。
- `cmd/snaplite/main.go`：`RunApplication` → 打开隐藏宿主窗口 → 加托盘（菜单：截图/长截图/剪切板历史/退出，前三项暂时只打日志）。
- `viva.toml`、`.gitignore`（`build/`）、`README.md`（项目根，简述 + 构建命令）。

完成标准：通用标准 + `cmd/snaplite` 能编译。

## M1 平台层

按 04 文档实现 `internal/platform`，顺序：

1. `platform.go` 接口与错误、`platform_other.go`。
2. macOS：Init / PostMain / Displays / CaptureDisplay / CaptureRect / 权限 / RaiseOverlay / SetExcludedFromCapture / RegisterHotkey / SetClipboardImage / WatchClipboard / ClipboardConcealed / ScrollAt / MoveCursor / ActivateApp。P1 的 WindowAt、LaunchAtLogin 可留 `ErrUnsupported` 桩。
3. Windows：同上清单。
4. 纯函数单测（键码、修饰键、坐标翻转、像素格式转换、DIB 头）。
5. `cmd/platform-probe`（`//go:build probe`）。

完成标准：通用标准 + `go build -tags probe ./cmd/platform-probe` 与其 Windows 交叉编译通过。

## M2 配置、标注模型、栅格化

1. `config`：Load/Save/默认值/ParseHotkey/FormatHotkey + 单测（含非法热键字符串）。
2. `annotate`：Document、Undo/Redo、Shift 约束、画笔平滑、箭头几何 + 单测。
3. `raster`：ToBGRA、Compose、EncodePNG、Thumbnail + 单测（关键像素断言）+ `ToBGRA` 4K benchmark。

完成标准：通用标准 + `go test -bench=. -run=^$ ./internal/raster` 输出 4K ToBGRA 耗时（记录到本文件末尾的「测量记录」）。

## M3 区域截图（遮罩 + 编辑）

1. `internal/ui`：主题 token、图标 path、工具栏与属性条组件（纯 painter 函数，输入状态 → 画 + 返回点击）。
2. `capture`：Session、坐标换算 + 单测。
3. `overlay`：State、Controller、输入映射、Paint、工具栏放置规则（纯函数单测：上下左右边界四种情况）。
4. `shell.StartCapture`：截屏 → 开遮罩 → RaiseOverlay → 结果处理（复制 / 保存 / 取消）。
5. `app.Driver` 测试（见 07 文档 §2）。

完成标准：通用标准 + overlay 的 Driver 测试全部通过。

## M4 剪切板历史

1. `history.Store` + 单测（去重、容量淘汰、字节淘汰、损坏 index 恢复、Restore 移到最前）。
2. 监听接入 `shell`，截图完成时直接 `AddImage`。
3. 面板 UI + Driver 测试（列表渲染、键盘选择、Enter 恢复调用假 Clipboard、搜索过滤、清空二次确认）。
4. 托盘「剪切板历史」与热键接入。

完成标准：通用标准 + history 测试全过。

## M5 长截图

1. `longshot.Stitcher` + 05 文档 §5.2 规定的生成式测试。
2. `longshot.Session`（驱动循环用可注入的 `Capturer` / `Scroller` / `Clock` 接口，测试里用假实现模拟“页面滚动”，覆盖：正常到底、步长自适应、NoOverlap 回退、达到 MaxHeight、手动模式、Cancel 后 goroutine 退出——用 `goleak` 式检查：测试结束时 `runtime.NumGoroutine()` 回到初值）。
3. 控制条窗口、`editor` 窗口（瓦片绘制、缩放、滚动、标注）+ Driver 测试。
4. 从遮罩工具栏「长截图」和热键两个入口接入。

完成标准：通用标准 + longshot、editor 测试全过。

## M6 打磨与打包

1. P1 功能：窗口吸附、放大镜、开机启动、暂停记录、搜索框（若前面没做）。
2. 错误路径：无屏幕录制权限引导窗口、热键被占用提示、panic recover + 日志。
3. 托盘图标、应用图标 `assets/icon.png`（程序生成即可，`cmd/genicon`，`//go:build ignore`）。
4. `viva package` 打包；macOS 补 Info.plist 键（`scripts/package-mac.sh`）。
5. 测量并记录：strip 后二进制体积（macOS arm64、Windows amd64）、空闲内存（可选，需要真实运行，若未运行就写明未测）。
6. 更新根 `README.md`：功能、快捷键、构建、权限说明、已知限制。

完成标准：通用标准 + `go build -ldflags="-s -w"` 体积记录 + README 完整。
