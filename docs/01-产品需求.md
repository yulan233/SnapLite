# 01 产品需求

## 1. 定位

一个“打开就忘了它存在”的截图工具：常驻托盘/菜单栏，按快捷键立即截图，截完直接进剪切板。功能刻意做少，每个功能都做顺手。

目标平台：

| 平台 | 最低版本 | 说明 |
| --- | --- | --- |
| macOS | 14 Sonoma | 截屏使用 ScreenCaptureKit 的 `SCScreenshotManager`（macOS 14 起提供） |
| Windows | 10 1903+ / 11，x64 与 arm64 | Viva 的 Windows 后端为实验状态，需在真机验收 |

Linux 不在本期范围，但代码结构要允许以后加（平台层用 build tag 隔离，非支持平台返回 `ErrUnsupported` 能编译通过）。

## 2. 功能清单

优先级：P0 必须有，P1 应该有，P2 本期不做。

### 2.1 托盘 / 菜单栏（P0）

- 启动后不显示主窗口，只在 macOS 菜单栏 / Windows 通知区域显示一个图标。macOS 下不显示 Dock 图标。
- 点击图标弹出菜单：
  - 截图　`⌥F1` / `右Alt+F1`
  - 剪切板历史　`⌥F2` / `右Alt+F2`（2026-11-01 起；原 `⌥F2` 的长截图已取消，原 `⌥F3` 的旧默认值自动迁移）
  - 关闭全部钉图（没有钉图时禁用，2026-11-01 增加）
  - ——
  - 开机启动（勾选项，P1）
  - 打开截图保存目录
  - ——
  - 退出简截
- 菜单项标题里附带快捷键文本（Viva 的菜单不解析快捷键字符，直接写在标题里即可，例如 `截图    ⌥F1`）。
- 快捷键说明：macOS 用 Option（左右均可）+ F1/F2；Windows 只认**右** Alt + F1/F2（左 Alt 不触发，避免与 Alt+F4 等系统组合混淆）。Mac 键盘上 F1–F2 默认是亮度等媒体键，需要同时按住 `fn`，或在 系统设置 › 键盘 › 键盘快捷键 › 功能键 中打开“将 F1、F2 等键用作标准功能键”。

### 2.2 区域截图（P0）

流程：

1. 用户按快捷键或点菜单「截图」。
2. 立刻对**所有显示器**各截一张全屏图（冻结画面），然后在每个显示器上盖一个全屏、置顶、无边框的遮罩窗口，显示冻结画面 + 40% 黑色蒙层。
3. 鼠标移动时：自动识别鼠标下的窗口并高亮其边框（P1，“窗口吸附”）；没有识别结果时显示十字准线。
4. 按下拖动：画出选区，选区内无蒙层（显示原图），选区边框 1px 主题色，四角和四边中点有 8 个拖拽手柄，选区左上方显示尺寸 `1280 × 720`（物理像素）。
5. 松开后进入**编辑态**：选区下方（空间不足则上方，再不足则选区内底部）出现工具栏。
6. 编辑态下：
   - 拖手柄调整选区大小，在选区内（未选中标注工具时）拖动可移动选区。
   - 选择标注工具后在选区内绘制（见 2.4）。
7. 结束方式：
   - `Enter` / 双击选区 / 工具栏「✓ 完成」：把“选区图 + 标注”合成 PNG，写入系统剪切板，并加入剪切板历史，关闭遮罩。
   - `⌘S` / `Ctrl+S` / 工具栏「保存」：弹出系统保存对话框，默认文件名 `简截_20261101_093015.png`（截图质量设为 JPEG 时为 `.jpg`，见 2.8），默认目录为上次保存目录（首次为系统“图片”目录下的 `简截` 文件夹）；保存成功后同时复制到剪切板（始终是无损 PNG）。
   - 工具栏「钉住」（2026-11-01 增加，在原「长截图」按钮的位置）：把“选区图 + 标注”钉在桌面上选区原来的位置（见 2.7），关闭遮罩；不复制、不加入剪切板历史。
   - `Esc`：编辑态下第一次 `Esc` 若有正在画的标注则取消该笔；否则直接退出截图，不留任何东西。右键单击同 `Esc`。
8. 放大镜（P1）：拖选时在鼠标右下方显示 8 倍放大的 15×15 像素网格和当前像素颜色 `#RRGGBB`，按 `C` 复制颜色值。

### 2.3 长截图（已取消）

> 2026-11-01：长截图（自动/手动滚动拼接、控制条、长图编辑器）按用户要求取消，相关代码、托盘菜单、工具栏按钮、设置项与配置字段均已删除。原长截图的快捷键 `⌥F2` / `右Alt+F2` 改给剪切板历史。

### 2.4 标注编辑（P0）

工具（同时只能选中一个，再次点击取消选中回到“移动/调整选区”）：

| 工具 | 操作 | 说明 |
| --- | --- | --- |
| 矩形 | 拖动 | 空心框；按住 `Shift` 为正方形 |
| 椭圆 | 拖动 | 空心；按住 `Shift` 为正圆 |
| 箭头 | 拖动 | 起点到终点，终点带实心三角箭头 |
| 画笔 | 按住拖动 | 自由曲线，平滑处理 |

公共属性（工具选中时在工具栏下方出现二级属性条）：

- 颜色：红 `#F04438`（默认）、黄 `#F5B800`、绿 `#12B76A`、蓝 `#2E90FA`、黑 `#101828`、白 `#FFFFFF`。
- 粗细：细 2px、中 4px（默认）、粗 8px（以截图物理像素计）。
- 撤销 `⌘Z` / `Ctrl+Z`，重做 `⌘⇧Z` / `Ctrl+Y` / `Ctrl+Shift+Z`。
- 已画的标注不可再选中编辑（P2），只能撤销。

### 2.5 剪切板历史（P0）

- 记录内容：系统剪切板里出现的**图片**和**纯文本**（包括其他程序复制的，不只是简截自己的截图）。
- 去重：与最近一条内容相同（哈希一致）时不新增，只把它挪到最前。
- 容量：最多 100 条，超出删最旧的；图片总占用超过 500MB 时也删最旧的。
- 持久化：退出后保留，下次启动可见。
- 隐私：密码管理器等标记为“隐藏/临时”的剪切板内容不记录（macOS `org.nspasteboard.ConcealedType` / `org.nspasteboard.TransientType`；Windows `ExcludeClipboardContentFromMonitorProcessing`、`CanIncludeInClipboardHistory = 0`）。
- 面板：快捷键打开一个居中的浮动面板（失焦自动关闭），宽 420、高 560：
  - 顶部搜索框（P1）：按文字过滤，图片条目不参与过滤。
  - 列表：每条一行，图片显示缩略图（最高 96px）+ 尺寸，文字显示前两行 + 字数；右侧显示相对时间（“刚刚”“3 分钟前”“昨天”）。
  - `↑↓` 选择，`Enter` 或单击：写回剪切板并关闭面板；`Delete`/`Backspace`：删除该条。
  - 右键菜单（2026-11-01 增加）：在某一行上右键，在指针处弹出菜单（不超出面板）：复制 / 粘贴（不能粘贴时不显示）/ 钉到桌面 / 保存到本地… / 删除。点菜单外或按 `Esc` 关闭菜单（不关闭面板）。
  - 保存到本地：先关闭面板再弹出保存对话框。文字保存为 UTF-8 的 `.txt`，默认文件名 `剪切板_20261101_093015.txt`；图片按截图质量设置保存为 PNG 或 JPEG，默认文件名 `简截_20261101_093015.png` / `.jpg`。取消对话框什么也不做。
  - 底部：「清空历史」（需二次确认）。
- 托盘菜单「暂停记录」勾选项（P1）。
- 复制与快速粘贴（2026-11-01 增加）：
  - 选中或鼠标悬停的行显示「复制」「钉住」「粘贴」按钮（「钉住」2026-11-01 增加）；其余行右侧显示 `⌘1`…`⌘9`（Windows `Ctrl+1`…）。
  - 点击条目 / `Enter`：默认只复制（设置里可改为“复制并粘贴”）；`⌘↵` / `Ctrl+↵` 做另一个动作；`⌘1–9` / `Ctrl+1–9` 直接粘贴第 1–9 条。
  - 粘贴：关闭面板，回到打开面板前的前台应用，模拟 `⌘V` / `Ctrl+V`。macOS 需要“辅助功能”权限，没有时内容仍会复制，并弹出系统授权提示。
  - 防重复：同一内容在历史里只保留一条（按内容哈希，再次复制只移到最前）；恢复的文字与剪切板当前内容相同时不重复写入；简截自己写入剪切板引起的变化不再被当作新的复制记录。

### 2.6 设置（P1，最小化）

> 2026-11-01 更新：已加设置窗口（托盘「设置…」），分四个标签页：
> - **快捷键**：录制和修改两个快捷键（截图、剪切板历史）、恢复默认。
> - **截图**：图片质量、分辨率（见 2.8）、打开截图保存目录，并说明“质量只影响保存的文件；复制到剪切板始终是无损 PNG”。
> - **剪切板**：是否记录历史、是否记录文字、最多保存条数（20/50/100/200/500/1000）、图片最多占用（100 MB/500 MB/1 GB/2 GB）、点击条目时“仅复制 / 复制并粘贴”、辅助功能权限引导。调低上限时立即删除最旧的条目。
> - **通用**：开机启动。
> 所有修改立即生效并写入 config.json（新增字段 `history.clickAction`：`"copy"` / `"paste"`；`capture.quality`、`capture.scale`）。

本期不做设置窗口。配置文件 `config.json`（位置见 05 文档）可改：快捷键、保存目录、历史条数上限、是否记录文本、截图质量与分辨率。文件不存在时用默认值并写出一份。

### 2.7 钉图（P1，2026-11-01 增加）

把截图或剪切板历史里的一条内容钉在桌面上，浮在其他应用之上，不抢焦点，在所有桌面空间可见。

- 入口：截图工具栏「钉住」（钉在选区原位）；剪切板历史行上的「钉住」按钮和右键菜单「钉到桌面」（钉在鼠标所在屏幕中央，多个时每个错开 24px）。
- 图片钉图：窗口逻辑尺寸 = 图片物理像素 / 屏幕缩放比（来自截图时用所在屏，来自历史时用主显示器），超过所在屏 80% 时等比缩小；1px 浅色边框。
- 文字钉图：卡片背景、13px 字、内边距 12、最宽 360 自动换行，最高为屏幕的 60%，超出部分以省略号截断。
- 操作：按住拖动移动；**双击**关闭；窗口获得焦点后 `Esc` 关闭；右键菜单：复制 / 保存到本地… / 取消钉住（保存规则同 2.5）。钉图比菜单还小时，菜单打开期间窗口临时变大。
- 钉图不持久化，退出简截时全部关闭；托盘「关闭全部钉图」一次关闭所有钉图。

### 2.8 截图质量（P1，2026-11-01 增加）

- 图片质量：原图（PNG 无损，默认）/ 高（JPEG 92%）/ 中（JPEG 80%）/ 低（JPEG 60%）。**只影响保存成文件**（截图「保存」、历史和钉图的「保存到本地…」）；复制到剪切板、存入历史、钉图始终使用无损 PNG，保证各应用都能粘贴。
- 分辨率：原始（默认，按物理像素）/ 标准 1×（按屏幕缩放比把截图缩小到逻辑尺寸，面积平均）。1× 对剪切板、文件、历史、钉图都生效。

## 3. 非功能需求

| 项 | 要求 |
| --- | --- |
| 响应速度 | 按下截图快捷键到遮罩出现 ≤ 200ms（单 4K 屏，M 系列 Mac / 近三年 Windows 本） |
| 空闲占用 | 托盘常驻时 CPU ≈ 0%，内存 ≤ 60MB（不含历史图片缩略图） |
| 高 DPI | 截图默认按物理像素输出，不缩放（可在设置里选“标准 1×”）；遮罩上显示与屏幕 1:1 清晰 |
| 多显示器 | 每个显示器一个遮罩；选区限制在单个显示器内（跨屏选区为 P2） |
| 安装包大小 | 单平台 ≤ 25MB |
| 数据安全 | 不联网，不上传任何内容 |

## 4. 非目标（本期明确不做）

- 录屏、GIF、OCR、翻译、云同步、图床上传（钉图已于 2026-11-01 加入，见 2.7）。
- 文字标注、马赛克、序号标注、标注的二次选中编辑。
- 跨显示器选区、长截图（2026-11-01 取消）与“整页网页截图”。
- Linux 与 Web 版本。
