# 04 平台适配

`internal/platform` 是项目里**唯一**允许出现 cgo、Objective-C、Win32 syscall 的包。上层只看到下面的 Go 接口。

## 1. 统一接口（`platform.go`）

```go
package platform

var (
    ErrUnsupported      = errors.New("platform: unsupported")
    ErrPermissionDenied = errors.New("platform: permission denied")
    ErrHotkeyTaken      = errors.New("platform: hotkey already registered")
)

// Init 在 RunApplication 的 start 回调里、事件循环线程上调用一次。
func Init() error

// PostMain 把 fn 排到事件循环线程执行。任意 goroutine 可调，不阻塞。
func PostMain(fn func())

// ---- 显示器与截屏 ----
type Display struct {
    ID      uint32
    Bounds  Rect    // 屏幕逻辑坐标（主屏左上角原点，y 向下），含菜单栏/任务栏区域
    Scale   float64 // 物理像素 / 逻辑像素
    Primary bool
}
type Rect struct{ X, Y, W, H float64 }

func Displays() ([]Display, error)
// CaptureDisplay 抓整个显示器，返回物理像素、非预乘 RGBA。不含鼠标指针。
func CaptureDisplay(id uint32) (*image.RGBA, error)
// CaptureRect 抓屏幕逻辑坐标中的一块（长截图用）；rect 必须在单个显示器内。
func CaptureRect(displayID uint32, rect Rect) (*image.RGBA, error)
// 权限
func HasScreenCapturePermission() bool
func RequestScreenCapturePermission()      // macOS 触发系统弹窗；Windows 空操作
func HasAccessibilityPermission() bool     // macOS 自动滚动需要；Windows 恒 true
func RequestAccessibilityPermission()
func OpenPrivacySettings(pane string)      // "screen" | "accessibility"

// ---- 窗口辅助（Viva 不暴露句柄，用唯一标题定位本进程窗口） ----
// RaiseOverlay 找到标题为 title 的本进程窗口：置于最高层、覆盖 bounds（逻辑坐标，含菜单栏/任务栏）、
// 激活应用并让它成为键盘焦点窗口、不出现在任务切换器里。
func RaiseOverlay(title string, bounds Rect) error
// SetExcludedFromCapture 让窗口不被截进屏幕截图（长截图控制条用）。
func SetExcludedFromCapture(title string) error
// WindowAt 返回屏幕逻辑坐标点下最上层的“其他应用”窗口的逻辑矩形（窗口吸附，P1）。
func WindowAt(x, y float64, excludeOwn bool) (Rect, bool)
func ActivateApp()

// ---- 全局热键 ----
type Modifiers uint8 // ModCmdOrCtrl | ModShift | ModAlt | ModCtrl(仅 macOS 区分)
type Hotkey struct{ Mods Modifiers; Key rune } // Key 用大写字母或数字
// RegisterHotkey 回调在事件循环线程执行。返回的 unregister 幂等。
func RegisterHotkey(h Hotkey, fn func()) (unregister func(), err error)

// ---- 剪切板 ----
// SetClipboardImage 写入图片（同时写 PNG 与平台原生位图格式），清掉原有内容。
func SetClipboardImage(img *image.RGBA) error
// ClipboardChangeCount 单调递增的变化计数（macOS changeCount；Windows GetClipboardSequenceNumber）。
func ClipboardChangeCount() int64
// WatchClipboard 剪切板变化时在事件循环线程调用 fn。stop 幂等。
func WatchClipboard(fn func()) (stop func(), err error)
// ClipboardConcealed 当前剪切板内容是否被来源标记为“不要记录”。
func ClipboardConcealed() bool

// ---- 输入注入（长截图自动滚动） ----
// ScrollAt 在屏幕逻辑坐标 (x,y) 处发送纵向滚动，dy 为逻辑像素，正数向下滚（内容上移）。
func ScrollAt(x, y float64, dy float64) error
func MoveCursor(x, y float64) error

// ---- 杂项 ----
func SetLaunchAtLogin(enabled bool) error   // P1
func LaunchAtLogin() bool
```

文本剪切板读写、图片剪切板读取、打开路径、保存对话框直接用 Viva 的 `app` 包，不在这里重复。

非支持平台文件 `platform_other.go`（`//go:build !darwin && !windows`）全部返回 `ErrUnsupported`，保证 `go vet ./...` 在任意平台通过。

## 2. macOS 实现（`*_darwin.go` + `darwin.m`）

cgo 指令：

```go
/*
#cgo CFLAGS: -x objective-c -fobjc-arc -mmacosx-version-min=14.0
#cgo LDFLAGS: -framework Cocoa -framework ScreenCaptureKit -framework CoreGraphics -framework Carbon -framework ApplicationServices -framework ServiceManagement -mmacosx-version-min=14.0
#include "darwin.h"
*/
import "C"
```

### 2.1 Init / PostMain / 激活

- `Init`：`[NSApp setActivationPolicy:NSApplicationActivationPolicyAccessory]`（隐藏 Dock 图标；Viva 启动时设成了 Regular，我们在 start 回调里改回）。
- `PostMain`：Go 侧维护 `[]func()` 队列 + mutex；C 侧 `dispatch_async(dispatch_get_main_queue(), ^{ goDrainMain(); })`，`goDrainMain` 用 `//export` 导出。
- `ActivateApp`：`[NSApp activateIgnoringOtherApps:YES]`（macOS 14 起推荐 `[NSApp activate]`，两者都调，忽略弃用警告）。

### 2.2 显示器

- `NSScreen.screens`；`ID = [screen.deviceDescription[@"NSScreenNumber"] unsignedIntValue]`（即 `CGDirectDisplayID`）。
- `Bounds`：用 `CGDisplayBounds(id)`——它已是“主屏左上角原点、y 向下”的全局坐标，单位为点，正好匹配 Viva。
- `Scale`：`screen.backingScaleFactor`；最终以截图实际像素宽 / 逻辑宽为准。

### 2.3 截屏（ScreenCaptureKit）

```objc
// 同步包装：在后台线程调用，用 dispatch_semaphore 等异步结果；禁止在主线程上 wait（会死锁），
// 所以 CaptureDisplay 在 Go 侧总是放到 goroutine 里执行。
[SCShareableContent getShareableContentExcludingDesktopWindows:NO onScreenWindowsOnly:YES completionHandler:^(SCShareableContent *content, NSError *err) { ... }];
SCDisplay *display = /* content.displays 中 displayID == id 的那个 */;
SCContentFilter *filter = [[SCContentFilter alloc] initWithDisplay:display excludingApplications:@[ /* 本应用的 SCRunningApplication */ ] exceptingWindows:@[]];
SCStreamConfiguration *cfg = [SCStreamConfiguration new];
cfg.width  = display.width  * scale;   // 物理像素
cfg.height = display.height * scale;
cfg.showsCursor = NO;
cfg.pixelFormat = kCVPixelFormatType_32BGRA;
cfg.captureResolution = SCCaptureResolutionBest;
// CaptureRect: 额外设置 cfg.sourceRect = CGRectMake(相对显示器的逻辑坐标)，宽高按 scale 放大
[SCScreenshotManager captureImageWithFilter:filter configuration:cfg completionHandler:^(CGImageRef img, NSError *err) { ... }];
```

- 把 `CGImageRef` 画进 `CGBitmapContextCreate(..., kCGImageAlphaPremultipliedLast | kCGBitmapByteOrder32Big)` 的缓冲区，得到 RGBA；屏幕截图 alpha 恒为 255，预乘与否无差别。用 `C.GoBytes` 一次拷贝进 `image.RGBA.Pix`。
- **排除本应用窗口**：截图时排除自己（避免截到遮罩或控制条）。`SCShareableContent.applications` 中 `processID == getpid()` 的那个。
- 冻结截图发生在遮罩打开**之前**，所以区域截图本身不受影响；长截图期间控制条靠这个排除（以及 `SetExcludedFromCapture`：`window.sharingType = NSWindowSharingNone`，双保险）。
- `SCShareableContent` 查询较慢（几十 ms），在 `Init` 后和每次截图结束后异步预取并缓存，截图时先用缓存，失败再刷新一次。
- 权限：`CGPreflightScreenCaptureAccess()` / `CGRequestScreenCaptureAccess()`。`SCShareableContent` 在无权限时返回错误 → 映射为 `ErrPermissionDenied`。

### 2.4 遮罩窗口置顶（RaiseOverlay）

```objc
for (NSWindow *w in NSApp.windows) if ([w.title isEqualToString:title]) { target = w; break; }
target.level = NSScreenSaverWindowLevel;            // 高于菜单栏与 Dock
target.collectionBehavior = NSWindowCollectionBehaviorCanJoinAllSpaces
                          | NSWindowCollectionBehaviorFullScreenAuxiliary
                          | NSWindowCollectionBehaviorStationary
                          | NSWindowCollectionBehaviorIgnoresCycle;
target.hasShadow = NO;
target.movable = NO;
[target setFrame:<bounds 转 NSScreen 坐标（左下角原点）> display:YES];  // 绕过 constrainFrameRect 对菜单栏的限制
[NSApp activateIgnoringOtherApps:YES];
[target makeKeyAndOrderFront:nil];
```

- 坐标转换：`NSRect.origin.y = 主屏高度 - (bounds.Y + bounds.H)`。
- 如果 `setFrame` 仍被限制在菜单栏下方，用 `NSWindow` 子类不可行（窗口是 Viva 创建的），改为 method swizzling 不推荐；先试 `setFrame:` + `level` 提升后的效果，级别高于菜单栏时 AppKit 不再约束（实测为准），不行再记入偏差记录。
- 无边框窗口默认 `canBecomeKeyWindow` 可能为 NO，导致收不到键盘事件。先验证 Viva 的 frameless 窗口能否成为 key window（Viva 的 `WindowPanel` 能拿键盘焦点，说明其内部有处理）。若不能，`RaiseOverlay` 用 `object_setClass` 给该实例动态换一个覆盖 `canBecomeKeyWindow` 返回 YES 的子类（运行时创建一次）。

### 2.5 全局热键（Carbon）

- `RegisterEventHotKey(keyCode, modifiers, hotKeyID, GetApplicationEventTarget(), 0, &ref)`，修饰键映射：`cmdKey`、`shiftKey`、`optionKey`、`controlKey`。
- 字母到虚拟键码用 `kVK_ANSI_A` 等常量表（只需 A–Z、0–9）。
- `InstallApplicationEventHandler` 处理 `kEventClassKeyboard / kEventHotKeyPressed`，从 `EventHotKeyID.id` 找到 Go 回调；回调已在主线程。
- 返回 `eventHotKeyExistsErr` 时映射 `ErrHotkeyTaken`。Carbon 热键不需要辅助功能权限。

### 2.6 剪切板

- 写图片：`[pb clearContents]`，`NSPasteboardItem` 同时 `setData:png forType:NSPasteboardTypePNG` 与 `setData:tiff forType:NSPasteboardTypeTIFF`（TIFF 由 `NSBitmapImageRep` 生成，保证老应用能粘贴）。
- 变化：`NSPasteboard.generalPasteboard.changeCount`。macOS 没有剪切板变化通知，`WatchClipboard` 用一个 **800ms 的低频定时器**（`NSTimer` 加到主 run loop，`tolerance = 0.4s` 以便系统合并唤醒）比较 changeCount，变化时才调 fn。这是本项目唯一的常驻定时器，属于有意的例外，记录在案；配置 `history.enabled = false` 时不启动。
- 忽略本应用自己写入的变化：`SetClipboardImage` 写完后记下新的 changeCount，watch 回调里跳过它（history 已经直接 Add 过了）。
- Concealed：`[pb.types containsObject:@"org.nspasteboard.ConcealedType"]`，以及 `TransientType`、`AutoGeneratedType`。

### 2.7 滚动注入

- `CGEventCreateScrollWheelEvent2(NULL, kCGScrollEventUnitPixel, 1, -(int32)dy, 0, 0)`，`CGEventSetLocation` 到目标点，`CGEventPost(kCGHIDEventTap, ev)`。
- 需要辅助功能权限：`AXIsProcessTrustedWithOptions(@{kAXTrustedCheckOptionPrompt: @NO})` 检查；Request 时传 `@YES` 弹系统提示。
- 先 `CGWarpMouseCursorPosition` 把指针移到选区中心（很多应用按指针位置决定滚哪个视图），结束后移回原位置。

### 2.8 窗口吸附（P1）

`CGWindowListCopyWindowInfo(kCGWindowListOptionOnScreenOnly | kCGWindowListExcludeDesktopElements, kCGNullWindowID)`，按顺序（前到后）找第一个 `kCGWindowLayer == 0`、`kCGWindowOwnerPID != getpid()`、`kCGWindowBounds` 包含该点的窗口。该列表在截图开始时取一次缓存，拖选过程中不再查询。

### 2.9 开机启动（P1）

`SMAppService.mainAppService` 的 `registerAndReturnError:` / `unregisterAndReturnError:`（macOS 13+，仅在 .app 包里有效；非包运行返回 `ErrUnsupported`）。

## 3. Windows 实现（`*_windows.go`）

纯 Go，`syscall.NewLazyDLL("user32.dll")` 等方式加载；可用 `golang.org/x/sys/windows`。

### 3.1 Init / PostMain

- `Init`（事件循环线程）：`RegisterClassExW` + `CreateWindowExW(0, cls, "", 0, 0,0,0,0, HWND_MESSAGE, …)` 创建**消息专用窗口**，wndproc 用 `syscall.NewCallback`。Viva 的消息循环（`GetMessage/DispatchMessage`）会把发给该窗口的消息派发到我们的 wndproc。
- 确认 DPI 感知：`GetThreadDpiAwarenessContext`，不是 Per-Monitor V2 时调用 `SetThreadDpiAwarenessContext(DPI_AWARENESS_CONTEXT_PER_MONITOR_AWARE_V2)`。
- `PostMain`：队列 + `PostMessageW(hwnd, WM_APP+1, 0, 0)`；wndproc 收到后清空队列执行。
- 必须验证：Viva 的 start 回调线程就是之后跑消息循环的线程（文档如此描述）。若不是，在第一个窗口的 `OnWake`/`Paint` 中惰性创建消息窗口。

### 3.2 显示器

- `EnumDisplayMonitors` + `GetMonitorInfoW`（`rcMonitor`，物理像素）+ `GetDpiForMonitor(MDT_EFFECTIVE_DPI)`（shcore.dll）。
- `Scale = dpi / 96`；`Bounds` 换算到逻辑坐标：**以 Viva 的约定为准**。实现前先读 Viva `internal/platform/windows` 里 `ScreenX/ScreenY`、`Origin`、`Frame` 的换算代码，与其保持完全一致，并在 `platform_windows_test.go` 写注释说明依据。
- `ID`：`HMONITOR` 截断为 uint32 不安全，改为枚举序号，并在会话内保存 `HMONITOR` 映射。

### 3.3 截屏（GDI）

```
hdcScreen = GetDC(0)
hdcMem    = CreateCompatibleDC(hdcScreen)
hbm       = CreateDIBSection(hdcMem, BITMAPINFO{biWidth=w, biHeight=-h(自上而下), 32bpp, BI_RGB}, DIB_RGB_COLORS, &bits, 0, 0)
SelectObject(hdcMem, hbm)
BitBlt(hdcMem, 0,0,w,h, hdcScreen, 物理x, 物理y, SRCCOPY|CAPTUREBLT)
// bits 为 BGRA，逐像素交换 B/R 并把 A 置 255 → image.RGBA
```

- 4K 屏 BitBlt 约 20–40ms，满足要求。DXGI Desktop Duplication 更快但复杂，本期不做。
- `CAPTUREBLT` 会让分层窗口一起被截到；长截图时控制条靠 `SetWindowDisplayAffinity(hwnd, WDA_EXCLUDEFROMCAPTURE)`（Win10 2004+）排除，老系统退化为 `WDA_MONITOR`（显示为黑块，控制条在选区外，不影响拼接）。
- Windows 没有截屏权限概念：`HasScreenCapturePermission` 恒 true。

### 3.4 遮罩窗口置顶

- 用 `EnumThreadWindows(GetCurrentThreadId(), …)` + `GetWindowTextW` 按标题找到 Viva 创建的窗口。
- `SetWindowLongPtrW(GWL_EXSTYLE, ex | WS_EX_TOOLWINDOW | WS_EX_TOPMOST)`（不进任务栏和 Alt+Tab）。
- `SetWindowPos(hwnd, HWND_TOPMOST, 物理x, 物理y, 物理w, 物理h, SWP_SHOWWINDOW | SWP_FRAMECHANGED)`，覆盖任务栏。
- 抢前台：`AllowSetForegroundWindow(ASFW_ANY)` 无效时，用经典组合：`keybd_event(VK_MENU)` 按下抬起后 `SetForegroundWindow(hwnd)`；或 `AttachThreadInput` 到当前前台窗口线程再 `SetForegroundWindow`。由热键触发时系统通常允许抢前台。

### 3.5 全局热键

- `RegisterHotKey(msgHwnd, id, MOD_CONTROL|MOD_SHIFT|MOD_NOREPEAT, vk)`；`WM_HOTKEY` 进 wndproc，按 `wParam`(id) 调回调。
- 失败且 `GetLastError() == ERROR_HOTKEY_ALREADY_REGISTERED (1409)` → `ErrHotkeyTaken`。
- `ModCmdOrCtrl` 在 Windows 映射为 `MOD_CONTROL`。

### 3.6 剪切板

- 写图片：`OpenClipboard(msgHwnd)`（失败重试 5 次、间隔 20ms——其他程序可能占用）→ `EmptyClipboard` →
  - `CF_DIBV5`（或 `CF_DIB`）：`BITMAPV5HEADER` + 自下而上 BGRA 像素，`GlobalAlloc(GMEM_MOVEABLE)`；
  - 注册格式 `"PNG"`：PNG 字节（Office、浏览器、聊天软件优先读它，保留透明度）。
  → `CloseClipboard`。
- 变化：`AddClipboardFormatListener(msgHwnd)`，wndproc 收 `WM_CLIPBOARDUPDATE` 时调 fn（事件驱动，无定时器）。`ClipboardChangeCount` = `GetClipboardSequenceNumber()`。
- Concealed：`RegisterClipboardFormatW("ExcludeClipboardContentFromMonitorProcessing")`、`"CanIncludeInClipboardHistory"`（值为 0 时排除）、`"Clipboard Viewer Ignore"`，用 `IsClipboardFormatAvailable` 判断。

### 3.7 滚动注入

- `SendInput` 一个 `INPUT_MOUSE`，`dwFlags = MOUSEEVENTF_WHEEL`，`mouseData = -WHEEL_DELTA * 步数`（WHEEL_DELTA = 120）。逻辑像素到“格”的换算不精确，所以自动滚动不依赖滚动距离，拼接算法自己算偏移（见 05 文档 §5）。每步发送 `-120`（1 格），按选区高度决定每步发几格（经验值：选区高 / 100 格，至少 1 格），再由拼接结果自适应调整。
- 先 `SetCursorPos` 到选区中心（物理坐标），结束后移回。
- 不需要权限；`HasAccessibilityPermission` 恒 true。注意 UIPI：无法向以管理员身份运行的窗口注入，此时滚动无效果 → 拼接检测到“无变化”后提示“目标窗口无法自动滚动，请手动滚动”并切到手动模式。

### 3.8 窗口吸附（P1）

`WindowFromPoint` → `GetAncestor(GA_ROOT)` → `DwmGetWindowAttribute(DWMWA_EXTENDED_FRAME_BOUNDS)`（去掉不可见的阴影边框），跳过本进程窗口（`GetWindowThreadProcessId`）。截图开始时用 `EnumWindows` 预取 Z 序列表缓存。

### 3.9 开机启动（P1）

`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 写入 `"简截" = "<exe 路径>" --background`。

## 4. 平台层自测

平台层很难单测，要求：

- 每个平台一个 `*_test.go`，只测**纯函数**：键码映射、修饰键映射、坐标翻转、BGRA↔RGBA 转换、DIB 头构造。
- 一个 `cmd/platform-probe`（`//go:build probe`）小程序，手工运行时打印显示器列表、截一张主屏图存到临时目录、注册热键 5 秒等待按下、写一张测试图到剪切板。用于真机验收，不进发布包。
- `GOOS=windows GOARCH=amd64 go vet ./...` 与 `GOOS=windows GOARCH=arm64 go build ./...` 必须在 macOS 上通过。
