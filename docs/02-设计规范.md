# 02 设计规范

关键词：**安静、轻、不抢画面**。截图工具的主角是用户的屏幕内容，界面元素要少、小、有足够对比度但不花哨。

## 1. 原则

1. 遮罩上的 UI 只有：选区框、尺寸标签、工具栏、（可选）放大镜。不出现任何说明文字之外的装饰。
2. 只用一个强调色；标注颜色是“内容色”，不算界面色。
3. 图标统一线性风格、1.5px 描边、20×20 视框，用 `ui.PathBuilder` 画在代码里（不引入图标字体或位图）。
4. 所有可点击元素有悬停态和键盘焦点态（Viva 的 `Canvas.Hovered` / `FocusVisible`）。
5. 跟随系统深浅色：工具栏、面板、编辑器窗口用 `app.SystemAppearance()` 选择 `ui.LightTheme()` 或 `ui.DarkTheme()`，并 `app.WatchSystemAppearance` 跟随变化。遮罩上的蒙层与选区框不随主题变化。

## 2. 设计 Token

定义在 `internal/ui/theme.go`，所有界面代码只引用 token，不写字面量颜色。

### 2.1 颜色

| Token | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `Accent` | `#2E7CF6` | `#4C8DF8` | 选区边框、手柄、选中工具底色、主按钮 |
| `Mask` | `rgba(0,0,0,0.40)` | 同左 | 遮罩蒙层 |
| `Surface` | `#FFFFFF` | `#1F2023` | 工具栏、面板、控制条背景 |
| `SurfaceBorder` | `rgba(0,0,0,0.08)` | `rgba(255,255,255,0.10)` | 浮层 1px 描边 |
| `Text` | `#1D1F23` | `#ECEDEE` | 主要文字、图标 |
| `TextMuted` | `#6B7079` | `#9A9FA6` | 次要文字（时间、尺寸） |
| `Hover` | `rgba(0,0,0,0.06)` | `rgba(255,255,255,0.08)` | 按钮悬停底色 |
| `Selected` | `Accent` 14% 透明度 | `Accent` 24% 透明度 | 选中工具底色、列表选中行 |
| `Danger` | `#E5484D` | `#F2555A` | 取消按钮图标悬停、清空历史 |
| `LabelBg` | `rgba(0,0,0,0.72)` | 同左 | 尺寸标签、放大镜信息底色（遮罩上始终用深色） |

### 2.2 尺寸（逻辑像素）

| Token | 值 |
| --- | --- |
| 圆角：浮层 / 按钮 / 色块 | 10 / 6 / 4 |
| 工具栏高度 | 40 |
| 工具按钮 | 32×32，图标 20×20 |
| 按钮间距 / 分组间距 | 2 / 8（分组之间加 1×20 的分隔线，颜色 `SurfaceBorder`） |
| 浮层与选区间距 | 8 |
| 选区边框 / 手柄 | 1px / 7×7 白底 + 1px `Accent` 描边方块 |
| 阴影 | `canvas.Elevate(bounds, 10, ui.ShadowLevel…)` 取中等层级 |

### 2.3 字体

用 Viva 默认系统字体（macOS 苹方 / SF，Windows 微软雅黑 / Segoe UI）。

| 用途 | 字号 | 字重 |
| --- | --- | --- |
| 尺寸标签、放大镜信息 | 12 | 500，等宽数字 |
| 面板列表正文 | 13 | 400 |
| 面板次要信息 | 12 | 400，`TextMuted` |
| 控制条 | 13 | 500 |

## 3. 界面布局

### 3.1 截图遮罩

```
┌──────────────────────── 整个显示器 ────────────────────────┐
│ ░░░░░░░░░░░░░░░░ 40% 黑色蒙层（冻结画面之上）░░░░░░░░░░░░░ │
│ ░░░░░ ┌ 1280 × 720 ┐  ← 尺寸标签：选区左上角上方 6px，     │
│ ░░░░░ ■─────■─────■     放不下时放到选区内左上角            │
│ ░░░░░ │  原 图 区  │                                       │
│ ░░░░░ ■           ■  ← 8 个手柄                           │
│ ░░░░░ │            │                                      │
│ ░░░░░ ■─────■─────■                                       │
│ ░░░░░        ┌───────────────────────────────────────┐    │
│ ░░░░░        │ ▢ ◯ ↗ ✎ │ ↶ ↷ │ ⇣长截图 │ ⤓ ✕ ✓ │ ← 工具栏，右对齐选区右边 │
│ ░░░░░        └───────────────────────────────────────┘    │
└──────────────────────────────────────────────────────────┘
```

- 未开始拖选时：全屏蒙层 + 鼠标处十字准线（1px 白色 60% 透明度横竖线贯穿屏幕），屏幕顶部居中一个提示胶囊：“拖动选择区域 · 右键或 Esc 退出”（长截图模式下：“框选要滚动的区域”），2 秒后淡出。
- 工具栏分组：`[矩形 椭圆 箭头 画笔] | [撤销 重做] | [长截图] | [保存 取消 完成]`。「完成」是唯一带 `Accent` 实心底色的按钮（白色对勾）。长截图模式下不显示标注组和「长截图」按钮，「完成」改名“开始滚动”。
- 属性条：选中标注工具时，在工具栏正下方 6px 出现，高 36：6 个 18×18 圆形色块（选中的外加 2px `Accent` 环）+ 分隔线 + 3 个粗细圆点（直径 4/7/11）。
- 工具栏放置规则：优先选区正下方右对齐；下方空间不足放选区上方；都不足放选区内部底部；水平方向始终夹在显示器内。

### 3.2 长截图控制条

- 尺寸 300×44 浮层，位于选区下方 8px 居中（不足则上方），不得与选区重叠（重叠会被截进去）。
- 内容：左侧状态文字“正在滚动… 已拼接 3 屏 · 2400px”，右侧「取消」文字按钮、「完成」主按钮。
- 选区本身用四条 2px `Accent` 线画在选区**外侧**（4 个细长的独立窗口，或省略，见 05 文档），提示用户正在截哪里。

### 3.3 编辑器窗口（长截图结果）

- 普通带标题栏窗口（`WindowCustomTitlebar`），标题“长截图 · 1280 × 8640”，初始宽度 = min(图宽/缩放 + 48, 屏幕 80%)，高度 = 屏幕 80%。
- 顶部 44px 标题栏区域内放工具栏（与遮罩工具栏同一组件，去掉「长截图」「取消」），右侧「复制」「保存」。
- 主区域：浅灰底（`#F2F3F5` / `#151619`），图片居中、可滚轮纵向滚动；宽度超出窗口时等比缩放显示（标注坐标始终以原图像素存储）。
- 关闭窗口时若有未复制/未保存的标注，弹 Viva 的 `Dialog` 询问“放弃修改？”。

### 3.4 剪切板历史面板

```
┌──────────── 420 × 560，圆角 10 ────────────┐
│  🔍 搜索剪切板历史                         │  ← 输入框 高 36
├───────────────────────────────────────────┤

│ 这是一段从网页复制的文字，第二行…   昨天   │
│                 ……                         │
├───────────────────────────────────────────┤
```

- 选中行底色 `Selected`，悬停行底色 `Hover`。
- 空状态：居中图标 + “复制的图片和文字会出现在这里”。

## 4. 动效

- 一律克制：提示胶囊淡出 200ms，工具栏出现 120ms 透明度过渡。其余（选区、拖动、绘制）即时响应，无动画。
- `app.ReduceMotion()` 为真时关闭全部过渡。
- 动效通过 Viva 的帧调度临时触发，结束后不再重绘（遵守 Viva“空闲不绘制”规则）。

## 5. 应用图标

- 托盘图标：模板图（macOS template image，单色随菜单栏变色），图形为“取景框四角 + 中间一个小圆点”，16×16 与 32×32 两种尺寸，在代码中用 `ui.Path` 绘制后栅格化，或放一个 PNG 到 `assets/`。
- 应用图标（打包用）：1024×1024 PNG，圆角方形，`Accent` 渐变底 + 白色取景框，放 `assets/icon.png`，由 `viva package` 生成各平台格式。
