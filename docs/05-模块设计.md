# 05 模块设计

## 1. `config` — 配置与数据目录

```go
type Config struct {
    Hotkeys struct {
        Capture   string `json:"capture"`    // 默认 macOS "Option+F1"，Windows "RightAlt+F1"
        LongShot  string `json:"longshot"`   // 默认 "Option+F2" / "RightAlt+F2"

func Load() (*Config, error)     // 缺省字段补默认值；文件不存在则写出默认

```

## 2. `capture` — 截图会话

```go
type Frame struct {
    Display platform.Display
    Image   *image.RGBA   // 物理像素原图
    Bitmap  ui.Bitmap     // 同一份内容的预乘 BGRA，供 Viva 绘制；ID 全局唯一递增
}
type Session struct {
    Frames []Frame
    Mode   Mode            // ModeRegion | ModeLongShot
    Windows []platform.Rect // P1 窗口吸附用的窗口矩形缓存（逻辑坐标，前到后）
}
func Begin(mode Mode) (*Session, error)  // 枚举显示器 + 并发截全部屏
func (f *Frame) Crop(r image.Rectangle) *image.RGBA     // 图像坐标裁剪（拷贝）
func (f *Frame) ToImage(p ui.Point) image.Point          // 窗口逻辑坐标 → 图像坐标（乘 scale 并取整）
func (f *Frame) ToWindow(p image.Point) ui.Point
```

- RGBA → 预乘 BGRA 转换放 `raster.ToBGRA(dst []byte, src *image.RGBA)`，复用缓冲。4K 屏单次转换应 < 15ms；写个 benchmark。
- 会话结束（完成/取消）时显式把 `Frames` 置 nil，避免大图常驻内存。

## 3. `annotate` — 标注模型

```go
type Tool uint8      // ToolNone, ToolRect, ToolEllipse, ToolArrow, ToolPen
type Color struct{ R, G, B, A uint8 }
type Shape struct {
    Tool   Tool
    Color  Color
    Width  float32          // 图像像素
    Points []image.Point    // Rect/Ellipse/Arrow: [起点, 终点]；Pen: 采样点（已平滑）
}
type Document struct {
    Shapes  []Shape
    redo    []Shape
    Draft   *Shape          // 正在画的这一笔，松开鼠标后 Commit
    Tool    Tool
    Color   Color
    Width   float32
}
func (d *Document) Begin(p image.Point)
func (d *Document) Extend(p image.Point, shift bool)   // shift: 正方形/正圆/箭头 45° 吸附
func (d *Document) Commit()                            // 太小的形状（<3px）丢弃
func (d *Document) CancelDraft() bool
func (d *Document) Undo() bool
func (d *Document) Redo() bool
func (d *Document) Dirty() bool
// 屏幕绘制：把每个 Shape 转成 ui.Path 画到 canvas。toWindow 把图像坐标映射到窗口坐标。
func Draw(canvas *ui.Canvas, d *Document, clip ui.Rect, toWindow func(image.Point) ui.Point, scale float32)
```

- 画笔平滑：采样时与上一点距离 < 2 图像像素的点丢弃；绘制时相邻点之间用中点二次贝塞尔（`QuadTo(p[i], mid(p[i], p[i+1]))`）。
- 箭头几何（屏幕绘制与栅格化共用，放 `annotate/geometry.go`）：头长 `max(10, 4*w)`、头半宽 `max(5, 2*w)`；杆画到头的底边为止，头为实心三角形。
- 每次 Paint 都重新生成 Path 会分配：用每个 Shape 缓存一个 `ui.Path`（`ui.NewPath` 拷贝一次），只有 Draft 每帧用 `canvas.PathBuilder()` 重建。缓存随 Shape 存在 `Document` 的并行切片里，Undo/Redo 时同步。
- `ui.Path` 的视框（view box）：用 `Path(width, height)` 时传入与 `bounds` 同尺寸的视框，坐标直接写窗口坐标，`bounds` 为该形状的包围盒或整个选区（实现时以 Viva `ui/path.go` 的语义为准，写一个 Driver 测试确认坐标映射正确）。

## 4. `raster` — 输出合成

```go
func ToBGRA(dst []byte, src *image.RGBA) []byte
func Compose(base *image.RGBA, shapes []annotate.Shape) *image.RGBA   // 拷贝 base 后把标注画上去
func EncodePNG(img *image.RGBA) ([]byte, error)                       // png.Encoder{CompressionLevel: png.BestSpeed}
func Thumbnail(img image.Image, maxSide int) *image.RGBA              // 盒式缩小，用于历史面板
```

抗锯齿描边算法（无依赖）：

1. 把每个 Shape 展开为线段序列（矩形 4 段；椭圆按周长每 2px 一段采样，至少 64 段；画笔先按 §3 做二次贝塞尔细分成线段；箭头杆 1 段 + 头三角形）。
2. 为每个 Shape 建一张覆盖度掩码（`[]uint8`，只覆盖该 Shape 包围盒 + 线宽）。对每条线段遍历其包围盒内像素，像素中心到线段的距离 `d`，覆盖度 `c = clamp(w/2 + 0.5 - d, 0, 1)`；掩码取 `max`（同一笔内自交不会叠加变深）。
3. 实心三角形：对包围盒内像素做 4×4 超采样点在三角形内测试，覆盖度取 max 写进掩码。
4. 用掩码 × 颜色 alpha 做 source-over 合成到图像。
5. 单元测试：用固定输入生成图像，断言关键像素（线中心像素为纯色、线外 > w 像素处为原色、对角线有中间灰度），不比对整图哈希。

## 5. `longshot` — 长截图

### 5.1 会话驱动

```go
type Options struct {
    Display  platform.Display
    Rect     platform.Rect    // 逻辑坐标
    Mode     Mode             // Auto | Manual
    MaxHeight int
}
type Progress struct { Frames, Height int; State State; Message string } // State: Running, Paused, Done, Failed
type Session struct { /* ... */ }
func Start(opt Options, onProgress func(Progress)) *Session   // onProgress 经 platform.PostMain 回到 UI 线程
func (s *Session) Finish()    // 用户点完成
func (s *Session) Cancel()
func (s *Session) Result() *image.RGBA
```

后台 goroutine 循环（会话结束即退出，不残留）：

```
first := CaptureRect(); stitcher.Add(first)
loop:
    Auto:   ScrollAt(center, step) ; sleep 220ms（等惯性滚动/渲染稳定）; 再截两次间隔 60ms，两次相同才算稳定（最多等 600ms）
    Manual: sleep 150ms
    f := CaptureRect()
    switch stitcher.Add(f) {
      case Appended(n):   progress；Auto 下若 n 小于 step 的 30%，说明滚动步长偏小，step *= 1.5（上限选区高 80%）
      case NoChange:      unchanged++；Auto 下连续 2 次 → Done（到底）；Manual 下不计
      case NoOverlap:     Auto 下 step /= 2 并回滚 ScrollAt(-step) 重试一次，再失败 → Done（保留已拼接）；Manual 下 Paused 提示“滚动过快”
    }
    高度 ≥ MaxHeight → Done
```

### 5.2 拼接算法 `Stitcher`

输入：同尺寸 `W×H` 的帧序列，内容只在纵向滚动。可能存在固定顶栏/底栏（sticky header/footer）。

1. **行签名**：每帧每行算一个 64 位哈希（对该行像素做 FNV-1a，忽略 alpha；为抗轻微噪声，像素每通道先右移 2 位）。得到 `sig[y]`。
2. **固定区检测**：比较新帧与上一帧，从顶部开始连续相等的行数为 `top`，从底部开始连续相等的行数为 `bottom`。滚动区域为 `[top, H-bottom)`。若 `top + bottom ≥ H-8` → `NoChange`。
3. **求偏移 dy**：在滚动区域内，对候选 `dy ∈ [1, scrollH-16]`，计算上一帧行 `y+dy` 与新帧行 `y` 签名相等的比例（只取滚动区域中“非纯色”行参与，纯色行签名高度重复会误导；若非纯色行少于 16 行则全用）。取匹配率最高的 `dy`，匹配率 < 0.9 → `NoOverlap`。候选按“上一次 dy 附近优先”顺序搜索，命中 ≥ 0.98 可提前结束。
   - 复杂度：`H` 约 1000~2000 行，暴力 O(H²) 次签名比较约 4M 次，可接受（< 10ms）。
4. **追加**：结果图 = 已有结果去掉最后 `bottom` 行 + 新帧 `[scrollH-dy+top, H-bottom)` 这一段 + 新帧底部 `bottom` 行（底栏只保留一份，始终在最末尾）。实现上维护“主体”和“当前底栏”两部分，`Result()` 时再拼起来。顶栏只出现在第一帧。
5. 结果用 `[]byte` 分块（每帧一块）存储，`Result()` 时一次性拷贝成 `*image.RGBA`，避免反复扩容大图。

测试：用程序生成一张 3000px 高、每行内容不同的“长页面”（含 60px 固定顶栏、40px 固定底栏、一段 200px 纯白区域），按随机步长切成视窗帧序列喂给 Stitcher，断言结果与原页面逐像素相等；再测步长 > 视窗高度时返回 `NoOverlap`；两帧相同返回 `NoChange`。

### 5.3 控制条窗口

- `OpenWindow(WindowFrameless)`，标题 `snaplite-longshot-bar`，打开后 `platform.RaiseOverlay` 置顶（bounds 为控制条自己的矩形）+ `platform.SetExcludedFromCapture`。
- 选区外框提示（P1）：用 4 个细长无边框窗口画在选区外侧 2px 处，同样排除截屏；不做也可接受。

## 6. `overlay` — 遮罩

### 6.1 状态

```go
type Phase uint8 // Idle(未拖选), Selecting(拖选中), Editing(已有选区)
type Drag uint8  // DragNone, DragNew, DragMove, DragHandle(0..7), DragDraw
type State struct {
    Phase     Phase
    Mode      capture.Mode
    Frame     *capture.Frame
    Sel       ui.Rect          // 窗口逻辑坐标，已规范化（W,H ≥ 0）
    Drag      Drag
    DragFrom  ui.Point
    SelAtDrag ui.Rect
    Hover     ui.Point         // 十字准线、放大镜
    Snap      *ui.Rect         // P1 吸附候选
    Doc       annotate.Document
    Toolbar   ui.Rect          // 本帧计算出的工具栏位置（Paint 中由纯函数计算，不存状态也可以）
}
```

一次截图会话有 N 个遮罩窗口（N 个显示器），但**只有一个活动选区**：鼠标在哪个屏按下，那个屏的 State 变为 Selecting，其他屏保持 Idle 蒙层且不响应拖选，直到会话结束。所有遮罩共享一个 `overlay.Controller`，持有 `[]*State` 和结果回调。

### 6.2 输入映射

| 事件 | Idle | Selecting | Editing（无工具） | Editing（有工具） |
| --- | --- | --- | --- | --- |
| 左键按下 | 记起点 → Selecting | — | 手柄上→DragHandle；选区内→DragMove；选区外→重新 DragNew | 选区内→`Doc.Begin`；手柄上仍可调整 |
| 移动 | 更新准线/吸附 | 更新 Sel | 更新拖拽 | `Doc.Extend` |
| 左键抬起 | 点击（无拖动）且有吸附 → Sel=吸附矩形，Editing | Sel 太小(<4px) → Idle；否则 Editing（长截图模式直接开始） | 结束拖拽 | `Doc.Commit` |
| 双击选区 | | | 完成 | 完成 |
| 右键 / Esc | 取消会话 | 回 Idle | 取消会话 | 有 Draft 则取消 Draft，否则取消会话 |
| Enter | | | 完成 | 完成 |
| 方向键 | | | 移动选区 1px（Shift 10px） | 同左 |
| ⌘/Ctrl+Z、⇧Z、Y | | | Undo/Redo | Undo/Redo |
| ⌘/Ctrl+S、C | | | 保存 / 完成 | 同左 |
| 1–4 | | | 选工具 | 选工具/取消 |

- 工具栏按钮用 `ui.Tree` 命名的 ID（`tree.ID(toolbar, "rect")` 等），点击用 `Clicked()` 判断；工具栏区域的指针事件不进入选区逻辑（`OnPointer` 里先判断命中目标是否为工具栏 hit）。
- 鼠标光标：选区内移动态 `move`，手柄上对应方向的 resize 光标，绘制态 `crosshair`（Viva 有设置光标形状的 API，见 `docs/system-integrations.md` 的 Cursor shape）。

### 6.3 Paint 顺序

1. `DrawBackdrop` / `DrawBitmap`：冻结画面铺满窗口（用 `ui.Surface.DrawPixels` 或 `DevicePixels` 保证 1:1 清晰）。
2. 蒙层：选区外的四个矩形 `Fill(Mask)`（不要整屏铺再“挖洞”）。
3. 标注：`annotate.Draw`，裁剪到选区。
4. 选区边框 + 手柄 + 尺寸标签。
5. 工具栏 + 属性条（`ui` 包共享组件）。
6. 十字准线 / 放大镜 / 提示胶囊。

### 6.4 结果

`Controller` 在 UI 线程上产出 `Result{Kind: Done|Save|LongShot|Cancel, Frame, SelImage image.Rectangle, Shapes}`，交给 `shell`。合成与 PNG 编码放后台 goroutine，完成后 `PostMain` 回来写剪切板（剪切板写入在 macOS 需主线程；Windows 用消息窗口作为 owner）。遮罩窗口在拿到 Result 后**立刻关闭**，不等编码完成，让用户感觉“瞬间完成”。

## 7. `editor` — 长图编辑窗口

- `OpenWindow(WindowCustomTitlebar)`，标题栏区域放共享工具栏组件。
- 视图状态：`ScrollY`、`Zoom = min(1, (窗口宽-48)/图宽)`（只缩小不放大），`OnScroll` 自己处理（返回 Handled），`OnResize` 时重算 Zoom。
- 长图可能远超 GPU 纹理上限（常见 8192 或 16384）：把长图按 **2048 行** 切成多个 `ui.Bitmap` 瓦片，Paint 时只画与可视区相交的瓦片。
- 标注坐标为原图像素；指针坐标转换：`img = (win - origin) / Zoom * 1 + (0, ScrollY/Zoom)`。
- 关闭时 `Doc.Dirty()` 且未复制/保存 → Viva `Dialog` 确认。

## 8. `history` — 剪切板历史

### 8.1 存储

```
<DataDir>/history/
    index.json          [{id, kind:"image"|"text", hash, created, size:[w,h], bytes, text?}]   最新在前
    <id>.png            图片原图
```

- `id`：`time.Now().UnixNano()` 的 base36。`hash`：内容 SHA-256 前 16 字节 hex（图片对 PNG 解码后像素算，避免同图不同编码重复）。
- 文本超过 64KB 的只存前 64KB 并标记 `truncated`；空白文本不记录。
- 写入：后台 goroutine 串行执行（一个带缓冲 channel 的 worker，**仅在有任务时运行**；没有任务时阻塞在 channel 上，不轮询）。`index.json` 原子写。
- 启动时读 index，校验文件存在，丢弃损坏条目。

### 8.2 Store API

```go
type Item struct { ID string; Kind Kind; Created time.Time; Text string; Size image.Point; Bytes int64; Hash string; Thumb *ui.Bitmap /*惰性生成*/ }
type Store struct { /* mu, items, dir, cfg */ }
func Open(dir string, limits Limits) (*Store, error)
func (s *Store) AddImage(img *image.RGBA) (Item, error)   // 去重：hash 已存在 → 移到最前
func (s *Store) AddText(text string) (Item, error)
func (s *Store) Items() []Item                             // 拷贝
func (s *Store) Delete(id string) error
func (s *Store) Clear() error
func (s *Store) LoadImage(id string) (*image.RGBA, error)
func (s *Store) Restore(id string, clip Clipboard) error   // 写回剪切板，并把条目移到最前
```

### 8.3 监听

```
platform.WatchClipboard(func() {           // UI 线程
    if 是本应用刚写入的 changeCount || ClipboardConcealed() || 暂停 { return }
    if app.HasClipboardImage() { png := app.ClipboardImagePNG() → 后台解码 → AddImage }
    else if 记录文本 { t := app.ClipboardText() → AddText }
})
```

### 8.4 面板 UI

- `OpenWindow(WindowPanel)`（无 Anchor → 屏幕居中；托盘点击打开时可带 Anchor）。失焦自动关闭。
- 用 `flex`：顶部文本框（`SetInitialFocus` 给搜索框）、可滚动列表、底栏。
- 列表虚拟化：只为可见行生成缩略图与 hit；缩略图在后台生成，`Invalidator` 唤醒重绘。
- 键盘：`↑↓` 移动选中、`Enter` 恢复、`Delete/Backspace`（搜索框为空时）删除、`Esc` 关闭。
- 时间文案函数 `RelativeTime(now, t)` 是纯函数，单测覆盖“刚刚 / N 分钟前 / N 小时前 / 昨天 / M月D日”。

## 9. `shell` — 应用壳


托盘图标：32×32 模板图，运行时用 `raster` 画出（取景框四角 + 中心圆点），不依赖文件；Windows 非模板，用 `Text` 色在浅/深任务栏下都可见的中灰 `#5F6368` 即可。
