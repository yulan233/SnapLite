# 07 测试与验收

## 1. 测试分层

| 层 | 工具 | 覆盖 | 是否打开窗口 |
| --- | --- | --- | --- |
| 纯逻辑单测 | `go test` | config（含热键迁移、截图质量）、annotate、raster（含 JPEG 编码、1× 缩小）、history.Store、坐标换算、工具栏放置、热键解析、相对时间、钉图尺寸与位置、保存文件名与扩展名 | 否 |
| UI 行为测试 | Viva `app.Driver` | overlay、history 面板（含右键菜单）、钉图、设置窗口 | 否 |
| 平台层 | 纯函数单测 + `cmd/platform-probe` 手工运行 | 键码、格式转换；真实截屏/热键/剪切板 | probe 不开窗口，但会触发权限 |
| 真机验收 | 下方 §3 清单 | 全流程 | 是（由用户或验收者执行） |

规则（来自 Viva 指南）：测用户依赖的行为，不测像素偏移或图元数量；绘制和输入路径给出每次 Paint 的分配次数（`go test -bench` + `-benchmem`）。

## 2. 必须有的 Driver 测试

用 `app.Driver` 驱动真实 painter 和输入路由，通过 `Snapshot` 检查标签、hit 区域、焦点。所有原生依赖用假实现注入。

### overlay

1. 初始状态显示提示文字“拖动选择区域”，没有工具栏 hit。
2. 拖动 (100,100)→(400,300)：出现尺寸标签，文本等于 `300×scale × 200×scale` 的格式化结果；松开后出现工具栏的 `完成`、`保存`、`取消` 等 hit。
3. 拖动右下手柄，尺寸标签更新；在选区内拖动，选区平移且尺寸不变；平移不越出屏幕。
4. 选择矩形工具（点击或按 `1`）→ 在选区内拖动 → `Undo` 可用；`⌘Z` 后标注数为 0，`⇧⌘Z` 恢复为 1。
5. `Enter`：Controller 产出 `Done`，结果裁剪矩形 = 选区 × scale，Shapes 数量正确。
6. `Esc`：编辑态下产出 `Cancel`；画到一半按 `Esc` 只取消该笔。
7. 选区贴近屏幕底部时工具栏位于选区上方；选区占满全屏时工具栏位于选区内底部。
8. 工具栏「钉住」：产出 `Pin`，带选区（图像像素与窗口坐标）和标注；工具栏不再有「长截图」。
9. 冻结画面是 backdrop，不会盖住蒙层、选区框和工具栏（`TestFrozenPictureIsBackdrop`）。

### history 面板

1. 空状态文案。
2. 注入 3 条（2 文字 1 图片），显示 3 行，底栏“共 3 条”。
3. `↓↓Enter`：假 Clipboard 收到第 3 条内容，面板请求关闭。
4. 输入搜索词只剩匹配的文字条目。
5. 「清空历史」→ 出现确认对话框 → 确认后 0 条。
6. 右键某一行：在指针处出现 复制 / 粘贴 / 钉到桌面 / 保存到本地… / 删除，各项调用对应回调；没有 `OnPaste` 时无「粘贴」；`Esc` 和点外面只关菜单；菜单不超出面板。
7. 选中行的「钉住」按钮调用 `OnPin`。

### 钉图

1. 双击关闭；`Esc` 关闭；单击不关闭。
2. 按住拖动：按屏幕坐标位移得到新的窗口矩形（注入的 Move 记录）。
3. 右键菜单 复制 / 保存到本地… / 取消钉住；`Esc` 和点外面只关菜单；比菜单小的钉图在菜单打开期间变大、关闭后恢复。
4. 叠放顺序：边框矩形在比图片更高的图层（`TestPinBorderAbovePicture`）。
5. 文字卡片最宽 360、最高屏幕 60%，超出以省略号结尾。

### 设置

1. 四个标签页「快捷键 / 截图 / 剪切板 / 通用」，每页的控件和文字都不超出窗口、不压住底部按钮（`TestSettingsTabsFitWindow`）。
2. 「截图」页：选择质量、分辨率立即写入配置。

## 3. 真机手工验收清单

每个平台（macOS 14+、Windows 11）都过一遍。勾选并记录问题。

### 启动与托盘
- [ ] 启动后无主窗口；macOS 无 Dock 图标，菜单栏有图标且随深浅色变化；Windows 通知区域有图标。
- [ ] 菜单各项可点，「退出简截」后进程结束。
- [ ] 首次截图 macOS 弹出屏幕录制授权；授权并重启应用后可正常截图。

### 区域截图
- [ ] 快捷键触发 ≤ 200ms 出现遮罩，遮罩覆盖菜单栏/任务栏，位于所有窗口之上（包括全屏应用所在空间，macOS）。
- [ ] 遮罩画面与真实屏幕 1:1 清晰（Retina / 150% 缩放）。
- [ ] 遮罩能立即收到键盘（Esc 有效），不需要先点击。
- [ ] 选区、手柄、移动、尺寸标签正确；尺寸为物理像素。
- [ ] 四种标注工具、六色、三档粗细、撤销重做可用；Shift 约束有效。
- [ ] 完成后粘贴到：微信/QQ、Word/Pages、浏览器输入框、画图/预览，图片正确且标注清晰。
- [ ] 保存对话框默认文件名与目录正确，保存的 PNG 与剪切板内容一致；质量设为 JPEG 时保存为 `.jpg`，剪切板里仍是 PNG。
- [ ] 分辨率设为“标准 1×”时，Retina / 150% 屏上的截图按逻辑尺寸输出（剪切板、文件、历史、钉图一致）。
- [ ] 多显示器：每个屏都有遮罩，在副屏截图正确（含不同缩放比的双屏）。
- [ ] 截图结果里不含鼠标指针、不含遮罩自身。

### 钉图
- [ ] 截图工具栏「钉住」：钉图出现在选区原位，大小与选区一致（Retina / 150% 缩放），截图没有进剪切板和历史。
- [ ] 钉图浮在其他应用窗口之上，出现时不抢走当前应用的键盘焦点；切换桌面空间 / 全屏应用时仍可见（macOS）。
- [ ] 按住拖动流畅、不跳动，跨显示器拖动正常（含不同缩放比的双屏）。
- [ ] 双击关闭，不被系统当成窗口缩放等手势拦截；点击钉图后按 `Esc` 关闭。
- [ ] 右键菜单出现在指针处；复制后可在其他应用粘贴；保存到本地按质量设置写出 PNG / JPEG；取消钉住有效；很小的钉图右键时菜单完整可见。
- [ ] 剪切板历史「钉住」/「钉到桌面」：图片和文字都能钉，出现在鼠标所在屏幕中央，多个依次错开；长文字截断为省略号。
- [ ] 托盘「关闭全部钉图」有效，没有钉图时为灰色；退出简截后钉图全部消失。

### 剪切板历史
- [ ] 在其他应用复制文字、复制图片，历史面板中出现；重复复制同一内容不重复记录。
- [ ] 从 1Password 等密码管理器复制的密码不被记录。
- [ ] 点击条目后在其他应用能粘贴出该内容。
- [ ] 重启应用后历史仍在；删除、清空有效。
- [ ] 面板失焦自动关闭；键盘操作有效。
- [ ] 右键某一行弹出菜单（位置在指针处、不超出面板）：复制 / 粘贴 / 钉到桌面 / 保存到本地… / 删除 均有效；点外面或 `Esc` 只关菜单。
- [ ] 保存到本地：面板先关闭再弹保存对话框；文字为 UTF-8 `.txt`（中文不乱码），图片按质量设置为 `.png` / `.jpg`；取消对话框无报错。

### 资源
- [ ] 常驻空闲 5 分钟，CPU ≈ 0%（活动监视器 / 任务管理器）。
- [ ] 空闲内存 ≤ 60MB。
- [ ] 连续截图 20 次后内存回落，无持续增长。
